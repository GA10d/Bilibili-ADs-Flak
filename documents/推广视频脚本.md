## 完整脚本

### 【开场钩子】0:00 - 0:35

**画面**：B站评论区截图快速闪过——"三连后找我"、"加V：xxx"、"企鹅号xxxx 每天免费推荐"、"刷粉找我"……画面逐渐叠加，变得密密麻麻。

**旁白**：
> 如果你是一个 B 站 UP 主，这些评论你一定不陌生。
>
> 卖课的、引流的、刷粉的、甚至还有搞颜色的——每天打开评论区，先得手动翻一遍，一条一条删广告，删到心态爆炸。
>
> 几十条还好说，要是上百条呢？要是有几百条楼中楼呢？
>
> 今天给大家介绍一个我自己写的开源工具——**Bilibili ADs Flak**，一个能帮你自动扫描、自动识别、一键删除广告评论的桌面助手。

**画面切换**：展示项目 LOGO（icon.png）+ 标题 "Bilibili ADs Flak"。

### 【项目介绍】0:35 - 1:00

**画面**：展示 GUI 主界面全景（showcase/menu.png），鼠标缓慢扫过各个区域。

**旁白**：
> 这个工具的工作流程非常简单，就四步：
>
> 1. 输入 BV 号，爬取评论
> 2. AI 自动判断哪些是广告
> 3. 你在表格里快速复核
> 4. 一键删除
>
> 它用的是 PyQt6 做的桌面界面，AI 识别用的是 DeepSeek，评论爬取和删除都调的是 B 站官方 API。完全开源，代码就在 GitHub 上。

---

### 【功能演示① —— 爬取评论】1:00 - 2:15

**画面**：操作录屏，逐步展示。

**旁白**：
> 先看怎么用。

**画面**：左侧栏特写——"自动导入 Cookie"按钮 + 登录成功后的 B站头像和昵称。

**旁白**：
> 第一步，导入你的 B 站 Cookie。点击「自动导入 Cookie」，它会自动从你的 Chrome、Edge 或 Firefox 里读取你的登录状态。不需要手动去浏览器里翻 SESSDATA，一键搞定。

**画面**：主工作区——粘贴 BV 号 → 点击「预览」→ 弹出视频信息（标题、评论总数）。

**旁白**：
> 然后，把你要清理的视频 BV 号粘贴进来，点「预览」确认一下视频对不对。

**画面**：点击「开始爬取」→ 进度条滚动 → 表格逐渐被评论填满。

**旁白**：
> 点「开始爬取」，它就会自动拉取这个视频的所有评论——不仅是一级评论，还有楼中楼的回复，默认会往下爬两层。
>
> 如果你评论特别多，中途关了软件也没关系。它支持**断点续爬**，下次打开接着上次的位置继续，不会重复爬。

**画面**：表格特写——序号、用户名、内容、点赞数。

---

### 【功能演示② —— AI 检测广告】2:15 - 3:15

**画面**：点击「检测广告评论」按钮，表格中逐批出现红色/绿色标记。

**旁白**：
> 评论爬完以后，点「检测广告评论」。
>
> 它会把你所有的评论分批发给 DeepSeek，用我编写的一套提示词来判断每一条是不是广告。因为有并发处理，速度很快，几百条评论也就几十秒。

**画面**：表格特写——红色行是广告，绿色行是正常评论。鼠标悬停在某条广告行上，展示「判定理由」列（如"出现微信号"、"售卖刷粉服务"）。

**旁白**：
> 红色的是广告，绿色的是正常评论。每条被标记的评论都会给出理由——比如"出现微信号"、"引流到QQ群"、"售卖课程"。
>
> 它把广告分了六大类：售卖、引流、诈骗、色情、刷粉刷量、其他广告。你可以一眼看出你评论区里都是些什么牛鬼蛇神。

**画面**：点击「只看广告」开关，非广告行全部隐藏，只剩下红色行。

**旁白**：
> 打开「只看广告」开关，就只显示被标记为广告的评论，方便你集中复核。

---

### 【功能演示③ —— 复核 + 删除】3:15 - 4:00

**画面**：演示手动修改——点击某条广告行的「广告」列文字，切换为「正常」。

**旁白**：
> AI 也不一定是百分之百对的。如果你发现某条被误判了，打开「手动修改」开关，直接点击就能切换判定，非常方便。

**画面**：打开白名单管理弹窗——分「用户白名单」和「评论白名单」两个 Tab。

**旁白**：
> 你还可以设置白名单。用户白名单——比如你认识的粉丝朋友，加了之后他们所有的评论都不会被删。评论白名单——某条特定评论你不想删，在表格里直接勾选就行。

**画面**：点击红色「删除广告评论」按钮 → 确认弹窗 → 删除进度 → 表格中广告行消失。

**旁白**：
> 确认无误之后，设置好删除限速，比如每分钟删 10 条，点「删除广告评论」。
>
> 为了安全，它会先验证你是不是这个视频的 UP 主。不是你的视频，想删也删不了。删除前还会弹一个确认框，删错了可没有后悔药。

### 【获取方式】4:45 - 5:15

**画面**：文字列表 + 代码块。

**旁白**：
> 这个项目完全开源，GitHub 链接在视频简介里。
>

>
> 1. 一台 Windows 电脑，装好 Anaconda
> 2. 一个登录了 B 站的浏览器
> 3. 一个 DeepSeek 的 API Key（注册就送额度，检测几千条评论也就几毛钱）

>
> 不会装也没关系，可以下载我打包好的 exe 版本，解压即用。

> - DeepSeek API 是按量计费的，虽然很便宜，但别把 Key 泄露出去
> - 删除评论不可逆，**先用小号视频测试**，确认流程没问题再上大号

## 录制建议

### 素材准备
- [ ] GUI 完整操作录屏（1920x1080，60fps）
- [ ] showcase/menu.png 高清截图
- [ ] B站评论区广告评论的真实截图（打码处理）
- [ ] icon.png 作为视频水印/角标
- [ ] 干净的桌面背景（或使用模糊背景 + 居中窗口）

### 录音
- 建议使用 Audacity 或 Adobe Podcast 降噪
- 语速：中等偏快（约 200-220 字/分钟），保持自然交谈感
- 背景音乐：轻快电子/lo-fi，音量低于人声 15-20dB

### 剪辑
- 操作步骤之间加简单的转场（dissolve / slide）
- 说到重点功能时给特写放大（scale 120-150%）
- 开头评论区截图堆叠建议做快速蒙太奇（每张 0.3-0.5 秒）
- 考虑在左上角放一个半透明的当前步骤指示器（"Step 1/4 爬取评论"）

### 封面建议
- 左侧：工具界面截图 + 红色箭头指向被标记的广告评论
- 右侧大标题："评论区广告？一键清理！"
